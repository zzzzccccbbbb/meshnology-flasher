## 决策摘要（v1）

- 走自研 SLIP / ROM bootloader 协议栈
- 用 WebUSB（不走 esptool.js）
- 范围：只 ESP32-S3 一款芯片
- 工时估计：10 周
- 风险：高

## 为何被推翻

见 v2 计划稿 §15。核心三点：
1. 产品级 web flasher（16302/xiaozhiinit）全部用 esptool-js + Web Serial
2. esptool.js 是 ~100KB JS，零 wasm / 零 binary，可直接 vite bundle
3. 自研协议栈只能 1 款芯片，工时 8 周+，用户感知差异 0

## 留档价值

如果未来要做"完全不依赖任何第三方库的纯自研协议栈"（例如嵌入式浏览器、安全要求极高的场景），本文档的 §3-§13 可作为协议层设计参考。
